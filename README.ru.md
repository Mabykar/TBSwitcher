# ⚡ TBSwitcher

Маленький переключатель Intel Turbo Boost в строке меню.
Нажали на молнию — Turbo Boost выключился (Mac холоднее, тише, батарея живёт дольше). Нажали ещё раз — включился.
**Без пароля администратора на каждый клик.**

🇬🇧 [English version](README.md)

> **Статус:** ранний релиз, сделан для Intel Mac на macOS Tahoe 26. Отчёты с других конфигураций очень приветствуются.
> **Только Intel Mac** — на Apple Silicon нет Turbo Boost, управлять нечем.

## Установка

Нужны Intel Mac, macOS 13 или новее и Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/Mabykar/TBSwitcher.git
cd TBSwitcher
bash install.sh
```

Установщик соберёт приложение, **один раз** спросит пароль администратора и запустит иконку ⚡.
При первом выключении Turbo Boost macOS попросит разрешить расширение ядра:
**Системные настройки → Конфиденциальность и безопасность → Разрешить**, затем перезагрузитесь и снова нажмите ⚡.

Если установщик остановился с сообщением *«No code-signed kext found»*, смотрите раздел [Подписанный kext](#подписанный-kext).

## Использование

| Действие | Что происходит |
|---|---|
| **Левый клик** по ⚡ | Переключить Turbo Boost |
| **Правый клик** по ⚡ | Меню: статус, восстановление выбора после сна/перезагрузки, запуск при входе, благодарности, выход |
| ⚡ закрашена | Turbo Boost **включён** (норма) |
| ⚡ перечёркнута | Turbo Boost **выключен** |

Удалить всё: `bash uninstall.sh`. Что-то не работает: `bash doctor.sh` выведет отчёт, который можно вставить в issue.

## Подписанный kext

macOS загружает только те расширения ядра, которые **подписаны и разрешены вами**. Отключать SIP для этого не нужно.
Kext'ы в [`Vendor/`](Vendor/) взяты из открытого репозитория Turbo Boost Switcher. Если у копии нет папки `_CodeSignature`,
она **не подписана**, и macOS её не примет (точно покажет `bash doctor.sh`).

Поэтому `install.sh` ищет подписанный kext в таком порядке:

1. `bash install.sh --kext /путь/к/DisableTurboBoost.64bits.kext`
2. `Vendor/DisableTurboBoost.64bits.kext`, если он подписан
3. `/Applications/Turbo Boost Switcher.app` — kext из официального приложения

Самый простой выход: скачайте бесплатное официальное приложение с <https://github.com/rugarciap/Turbo-Boost-Switcher>
(ссылка на скачивание есть в его README), перетащите в `/Applications` (запускать не обязательно) и снова выполните `bash install.sh`.
Путь «частично отключить SIP и поставить неподписанный kext» мы намеренно не поддерживаем.

## Как это работает

```
⚡ приложение в меню (вы)  ──XPC──▶  маленький helper (root, LaunchDaemon)  ──▶  kextutil / kextunload
                                      принимает только «вкл» / «выкл»           DisableTurboBoost.kext
```

Пока kext загружен, он выставляет бит отключения Turbo Boost в MSR-регистре процессора: **kext загружен = Turbo Boost выключен**.
Для загрузки kext нужен root, поэтому один раз ставится небольшой helper (это и есть единственный запрос пароля), который делает это по команде.
Он принимает ровно одну вещь — булево значение. Подробнее в [SECURITY.md](SECURITY.md).

## Вопросы и ответы

**Останется ли Turbo Boost выключенным после сна или перезагрузки?**
Другие утилиты на том же kext сообщают, что при пробуждении он может выгружаться. TBSwitcher запоминает ваш последний выбор
и применяет его заново после пробуждения и при запуске (в меню: *Restore my choice after sleep / reboot*, по умолчанию включено).

**Почему macOS просит разрешить расширение?** Она так делает для любого стороннего расширения ядра, один раз.

**Почему приложение не нотаризовано?** Для этого нужен платный Apple Developer ID. Пока вы собираете его сами из исходников, заодно можно прочитать каждую строку.
